SuperClicker

SuperClicker è una semplice applicazione in Java con interfaccia grafica che conta i click.

Cosa fa:

 - Mostra un contatore

  - Aumenta il numero ogni volta che premi il pulsante

  - Interfaccia grafica semplice (Java Swing)

Tecnologie usate:

-Java

-Java Swing

Come eseguirlo:

1)Scarica o clona il progetto

2)Aprilo con un IDE Java (NetBeans, IntelliJ, ecc.)

3)Avvia il file SuperClicker.java

Scopo:

Progetto base per imparare a usare Java e creare piccole interfacce grafiche.
